# Финансовое образование для взрослых

Одностраничный сайт курса «Финансовое образование для взрослых» на русском языке. Курс длится 5 дней и его проводит Манапбаева Нураим Замирбековна. Это информационный лендинг, а не платформа с уроками, прогрессом или личным кабинетом.

## Запуск

Требуется Node.js 20.9 или новее.

```bash
npm install
npm run dev
```

Откройте адрес, показанный Next.js (обычно `http://localhost:3000`). Для production-сборки используйте `npm run build`, затем `npm start`.

## Публикация на GitHub Pages

Проект настроен на статическую сборку и автоматическую публикацию через GitHub Actions.

1. Создайте публичный репозиторий на GitHub (например, `finansovaya-gramotnost`) и загрузите в него файлы проекта.
2. В репозитории откройте **Settings → Pages** и выберите **GitHub Actions** в разделе сборки и публикации.
3. Отправьте изменения в ветку `main` или `master`. Сборка и публикация запустятся автоматически; адрес появится в **Settings → Pages** и в завершённом запуске workflow.

Для репозитория `username.github.io` адрес будет `https://username.github.io/`. Для остальных репозиториев — `https://username.github.io/название-репозитория/`. Настройка базового пути для ресурсов применяется автоматически в GitHub Actions.

GitHub Pages публикует только статические файлы. Для связи по курсу сайт открывает WhatsApp по ссылке из `lib/contact.ts`. Форма заявки подставляет указанные контакты в сообщение; чтобы отправить заявку, пользователь должен подтвердить отправку в WhatsApp. Трекер сохраняет данные только в localStorage браузера пользователя.

## Структура

- `app/page.tsx` — лендинг: аудитория, программа, результаты, преподаватель, FAQ и переход в WhatsApp.
- `app/tracker/page.tsx` — отдельная страница учёта доходов и расходов.
- `components/site-header.tsx`, `components/site-footer.tsx` — якорная навигация и контакты.
- `components/course-receipt.tsx` — краткое содержание курса в виде карточки-квитанции на первом экране.
- `components/teacher-profile.tsx` — профиль преподавателя и поля для подтверждённых сведений от Нураим.
- `lib/contact.ts` — ссылка на WhatsApp для кнопок связи на сайте.
- `components/interactive-tools.tsx` — фильтр финансовых инструментов, трекер и чек-лист.
- `lib/content.ts` — 7 тем курса и справочник финансовых инструментов.
- `app/globals.css` — адаптивные стили в палитре и типографике приложенного HTML-макета.

## Заглушки, которые нужно заполнить

Все пункты ниже нужно проверить и заполнить перед публикацией. Сведения о преподавателе в профиле внесены по предоставленному описанию; названия предыдущих работодателей в нём не указаны.

- Фото Манапбаевой Нураим Замирбековны.
- Формат курса: онлайн или офлайн, место или платформа.
- Время занятий и часовой пояс (без публикации расписания занятий по дням).
- Стоимость и условия оплаты.
- Дата начала курса.
- Количество мест.
- Продолжительность одного занятия и наличие / срок доступности записей для FAQ.
- Контактный телефон, Telegram и email.

## Как менять тексты и фото

Тексты преподавателя и заглушки расположены в `components/teacher-profile.tsx`. Текст программы находится в массиве `courseTopics` в `lib/content.ts`: у каждой темы есть заголовок, краткое описание и результат обучения. Секции лендинга, сценарии аудитории, результаты и FAQ редактируются в `app/page.tsx`.

Замените блок-заглушку фото в `components/teacher-profile.tsx` на изображение Манапбаевой Нураим Замирбековны из `public/` (с её разрешения) и укажите осмысленный `alt`-текст. Общие цвета, сетка и адаптивность настроены в `app/globals.css`.

## Данные и дисклеймер

Записи трекера, пользовательские категории и чек-лист челленджа хранятся в `localStorage` текущего браузера и не отправляются на сервер. Данные не синхронизируются между устройствами; для резервной копии операций предусмотрен экспорт CSV. Связь по курсу открывается в WhatsApp.

Материалы курса носят образовательный характер и не являются инвестиционной рекомендацией.
